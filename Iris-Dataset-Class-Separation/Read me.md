#  Iris Dataset - Class Separation

این تکلیف به **جدا کردن کلاس‌ها در دیتاست Iris** می‌پردازد.

---

## ویژگی‌های دیتاست

دیتاست **Iris** دارای **۴ ویژگی اصلی** است:

- **Petal length** (طول گلبرگ)  
- **Petal width** (عرض گلبرگ)  
- **Sepal length** (طول کاسبرگ)  
- **Sepal width** (عرض کاسبرگ)  

> توجه: لزوماً برای جدا کردن کلاس‌ها به **هر ۴ ویژگی نیاز نیست**.

---

## نکات کلیدی

1️⃣ استفاده از **دو ویژگی گلبرگ (petal length و petal width)** معمولاً می‌تواند  
**۳ کلاس را تقریباً کاملاً از هم جدا کند**.  

2️⃣ اضافه کردن طول و عرض کاسبرگ کمک می‌کند، اما **ضروری برای جداسازی کامل نیست**.

---

## کاهش ابعاد و انتخاب ویژگی

برای کاهش تعداد ویژگی‌ها می‌توان از روش‌های زیر استفاده کرد:

- **PCA (Principal Component Analysis)**  
- **Feature selection / انتخاب ویژگی**

این روش‌ها کمک می‌کنند تا داده‌ها ساده‌تر شوند و همچنان امکان جداسازی کلاس‌ها حفظ شود.
